# 戰鬥公式採用決策（2026-11-01）

## 目標
以 https://github.com/zzbChina/BorderHelper 作為率土模擬器之非官方模擬基準，**不是**宣稱官方公式。

## 來源查核
- BorderHelper README 表示內建武將／戰法／模擬對戰與戰報系統。
- 作者註明對局資料自行收集，不保證完全正確。
- 目前公開原始碼主要呈現打包檔 `js/app.29fe9c06.js`，尚未抽取可重現且可獨立核對的傷害函式。
- 根目錄未見 LICENSE 檔案；在授權確認前不直接搬入整份程式碼或美術素材。

## 目前 GG 的狀態
- GG 仍使用 `stzb-pwa/index.html` 中示範傷害模型（約 250～850 隨機基礎值等）。
- `stzb-pwa/tactic-reference-batch1.json` 為參考戰法資料，尚未接入引擎。
- 不得把 GG 的示範戰報稱作 BorderHelper 計算結果。

## 移植完成的驗收條件
1. 可以核對來源程式的實際計算函式與使用授權。
2. 有獨立可測試的攻擊／防禦／謀略／兵力／增減傷模組。
3. 有戰法發動、指揮、生效時序、控制、持續傷害、治療、目標選擇和攻擊距離。
4. 使用固定亂數種子對比相同隊伍在 BorderHelper 的至少十組測試結果。
5. 測試通過後才把新引擎設為預設；舊模型明確標示為「展示」。
