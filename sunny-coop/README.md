# 晴舍｜雞舍氣象守護

黑底白字的響應式天氣網頁 App（PWA），供 Android Chrome 與桌面瀏覽器使用。預設場區為彰化縣芳苑鄉，可在地圖選點或輸入經緯度新增場區。

## 本機啟動

不需要安裝套件或編譯。在此資料夾執行：

```sh
python3 -m http.server 8080
```

開啟 http://localhost:8080 。若從儲存庫根目錄啟動，開啟 http://localhost:8080/sunny-coop/ 。

## 功能

- 溫度、相對濕度、風向、風速、下一完整小時降雨機率。
- 未來 24 小時溫度、濕度、風速與降雨趨勢。
- 地圖選點、經緯度輸入及定位選點；同時監測目前選取的場區。
- 自訂高溫、低溫、高濕、強風、降雨機率、迎風與高溫加高濕規則。
- 頁面開啟時每 10 分鐘更新，支援提醒間隔、暫停提醒、恢復通知與資料異常紀錄。
- 測試聲音、震動與系統通知（受裝置、權限與瀏覽器限制）。
- 於瀏覽器本機保存設定及最多 200 筆紀錄，可匯出 JSON。

## Android 使用

將此資料夾發布於 HTTPS 靜態網站後，以 Chrome 開啟，選單選擇「安裝應用程式」或「加入主畫面」。此版本為 PWA，沒有原生 Android APK。

## 資料與限制

- 天氣：Open-Meteo，https://open-meteo.com/ 。為戶外氣象模式估算，並非雞舍內實測；降雨機率為預報。實際採用模型格點可能與選取座標不同。
- 地圖：國土測繪中心臺灣通用電子地圖 WMTS，https://maps.nlsc.gov.tw/ 。臺灣以外可能無底圖，可直接輸入座標。
- 需有網路才能取得新天氣與地圖。服務條款、額度與商用需求請另查各資料提供者規範；正式商用部署前需確認資料使用授權。
- **背景伺服器與 Web Push 尚未實作。關閉網頁、鎖屏或系統暫停網頁後，不保證監測或提醒；安裝至主畫面不會改變此限制。**
- 設定與紀錄僅存於目前瀏覽器，不會跨裝置同步。清除網站資料會刪除它們。
- 門檻預設全部關閉；範例數值不是養殖標準，須自行設定。

## 檔案

`index.html`：介面；`style.css`：黑底白字版樣式；`app.js`：資料查詢與操作；`engine.mjs`：門檻判斷與資料解析；`sw.js`：快取及通知點擊處理；`manifest.webmanifest`：PWA 設定；`icon*`：圖示。

此資料夾可單獨部署，無須 Sites 的託管設定、金鑰或登入憑證。
